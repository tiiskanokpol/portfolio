White Post: Autonomous Inter-building Robot

Robotics & Navigation
Click to Zoom
PID Control Tracked Drive Design Motor Sizing Calculations LiDAR-free Navigation

Designed and engineered a prototype inter-building delivery robot optimized to carry documents between campus offices without relying on expensive 3D LiDAR. I designed the tracked chassis system, calculated optimal track lengths, and sized the high-torque DC motor for optimal performance on rough terrains.

Programmed the control unit using custom PID loops to stabilize motor velocity, enabling smooth navigation over campus sidewalks and grass surfaces.

White Post V.1

Suspension & Mechanical Design

Rocker-Bogie Suspension CAD Modeling Flexible Wheel Engineering

In the initial iteration of the inter-building robot, we developed a active Rocker-Bogie suspension framework for traversing stairs and high curbs. I calculated link kinematics, selected the DC motors, and modeled custom, flexible non-pneumatic compliance wheels to absorb physical impacts.

PLC-Based Control Logic for Bottle Molding

Industrial Systems
Industrial Molding Loop
Siemens TIA Portal PLC Ladder Logic HMI Screen Design

Designed and tested automation control sequences using Siemens TIA Portal to optimize high-volume plastic bottle blow molding processes. Programmed ladder logic code for sensory integration, heating controls, pneumatic timing, and implemented a functional HMI control terminal for real-time plant diagnostics.

OpenCV / Computer Vision Robotic Arm Kinematics Eye-in-Hand Calibration

Implemented smart sorting and QA automation by integrating open-source computer vision libraries with a 6-DOF robotic manipulator. Programmed eye-in-hand cameras for image classification, dimensional inspection, and coordinate translation mapping, enabling the arm to dynamically detect and sort misaligned production line products.
